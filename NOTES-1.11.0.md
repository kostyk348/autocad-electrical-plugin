# v1.11.0 — авто-слепки при сохранении

История ревизий теперь ведётся сама: каждый `QSAVE`/`SAVEAS` может оставлять слепок, но с
ограничениями, чтобы не забить диск и не тормозить работу.

## Новое

**`OMNI-AUTOSNAP`** — авто-слепки при сохранении.

| Параметр | Значение по умолчанию |
|---|---|
| Минимальный интервал между слепками | 60 секунд |
| Потолок слепков в час | 20 |
| Состояние | `_OMNI_HISTORY/autosnap.state` (`on`/`off`, по умолчанию включено) |
| Что делает слепок | срабатывает на `QSAVE`, `SAVEAS`, `SAVE`; пишет слепок + запись в манифест; при переполнении сам сжимает старые |

Команда без параметров показывает состояние, с ключом — переключает (`Вкл` / `Выкл` / `Состояние`).

Почему так: сохранение — самая частая точка, где теряются изменения, но и самая частая команда
вообще. Поэтому решение принимает чистая функция (`AutoSnapPolicy`): интервал, часовой потолок и
защита от переведённых назад часов. Состояние — три маленьких файла, поэтому на каждое сохранение
уходит O(1), а не чтение всей истории. Любая ошибка внутри обработчика ловится и пишется в лог:
сохранение чертежа не может упасть из-за плагина.

## История ревизий (из 1.10.0)

`OMNI-SNAP` · `OMNI-AUTOSNAP` · `OMNI-HISTORY` · `OMNI-ARCHIVE` · `OMNI-RESTORE` ·
`OMNI-LOG` · `OMNI-DIFF` · `OMNI-CLEAR` · `OMNI-TOGGLE` · `OMNI-NOTE`

Манифест `_OMNI_HISTORY/history.jsonl` хранит `файл, время, автор, описание, размер, sha256, prev→next`;
`OMNI-HISTORY` проверяет целостность цепочки, `OMNI-ARCHIVE` пакует старые слепки в ZIP,
`OMNI-RESTORE` откатывает к любой ревизии (с обязательным страховочным слепком `before-restore`).

## Установка

1. `El.Plugin.2024.installer.zip` → распаковать → в AutoCAD: `NETLOAD` → `El.Plugin.dll` → Enter на
   вопрос об автозагрузке → перезапустить AutoCAD.
2. Или `El.Plugin.2024.bundle.zip` → распаковать в `%APPDATA%\Autodesk\ApplicationPlugins\`.

Проверка загрузки:

```
sha256sum -c SHA256SUMS.txt                                     # Linux/macOS
Get-FileHash -Algorithm SHA256 El.Plugin.2024.installer.zip     # Windows
```
