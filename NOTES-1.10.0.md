# v1.10.0 — OMNI: история ревизий с цепочкой, сжатием и откатом

Полноценная надстройка: LISP-наработки перенесены в плагин, история версий чертежа стала
проверяемой и перестала занимать диск.

## Новое

**OMNI — история ревизий**

| Команда | Что делает |
|---|---|
| `OMNI-SNAP` | слепок + запись в `history.jsonl` (sha256 файла и звено цепочки `prev→next`); при переполнении сам сжимает старые слепки |
| `OMNI-HISTORY` | список ревизий и проверка целостности цепочки — покажет запись, на которой манифест правили руками |
| `OMNI-ARCHIVE` | спрашивает, сколько последних слепков оставить, остальные пакует в `archive/ГГГГ-ММ.zip` и удаляет оригиналы только после сверки длины |
| `OMNI-RESTORE` | откат к любой ревизии (и из ZIP тоже); перед откатом делает страховочный слепок `before-restore`, поэтому откат всегда обратим |

`OMNI-LOG`, `OMNI-DIFF`, `OMNI-CLEAR`, `OMNI-TOGGLE`, `OMNI-NOTE` — как раньше.

**Перенесены последние LISP-команды** (`el-tools`):

- `EL-HOTSPOTS` — тепловая карта плотности линий: сетка поверх габаритов чертежа, цвет от красного
  (плотно) к зелёному, слой `EL_HOTSPOTS`;
- `EL-CROSSREF` — ссылки на другие листы в тексте (`см. лист 5`, `Л. 12/3`, `Sheet 8`), сводка по
  листам и метки на слое `EL_CROSSREF`.

Теперь в плагине есть все **26 команд** AutoLISP из `el-tools` и `omni`.

## Надёжность

Убраны места, где большая схема могла подвесить AutoCAD:

- лабиринтный роутер: жёсткий бюджет **4 000 000** ячеек (было — расчёт из разброса точек, на обходе
  200 м при шаге 0.5 это 1.6·10¹¹ ячеек), шаг сетки укрупняется автоматически;
- растеризация препятствий — не больше **4096** проб на отрезок;
- сглаживание пути — бюджет **2 000 000** проверок, затем путь отдаётся без сглаживания;
- архивация истории — не больше **200** файлов за проход, скан папки — до **5000**;
- описание ревизии больше не попадает в имя файла как есть (`..\..\evil` больше не уводит файл из
  папки истории).

## Установка

1. `El.Plugin.2024.installer.zip` → распаковать → в AutoCAD: `NETLOAD` → `El.Plugin.dll` → Enter на
   вопрос об автозагрузке → перезапустить AutoCAD.
2. Либо `El.Plugin.2024.bundle.zip` → распаковать в `%APPDATA%\Autodesk\ApplicationPlugins\`.

Проверка целостности скачивания:

```
sha256sum -c SHA256SUMS.txt        # Linux/macOS
Get-FileHash -Algorithm SHA256 El.Plugin.2024.installer.zip   # Windows PowerShell
```
