# v1.13.0 — установщик одним файлом, без NETLOAD

Вопрос был простой: как поставить плагин без возни с `NETLOAD`. Ответ — `El.Tools.Setup.exe`:
двойной клик, кнопка «Установить», всё.

## Как ставить

1. Скачать **`El.Tools.Setup.exe`** (408 КБ, внутри обе сборки).
2. Запустить → «Установить».
3. Запустить AutoCAD. Всё: вкладка **«Электроавтоматика»** на ленте на месте.

`NETLOAD` больше не нужен: установщик кладёт bundle в `%APPDATA%\Autodesk\ApplicationPlugins\`,
а AutoCAD загружает оттуда плагины сам при старте.

Что делает установщик:

| Шаг | Детали |
|---|---|
| Определяет версии AutoCAD | читает `HKLM/HKCU\SOFTWARE\Autodesk\AutoCAD\R*` |
| Выбирает сборку | 2021–2024 → net48, 2027 → net10; для 2025/2026 сборки в установщике нет и он об этом честно пишет |
| Ставит | `ApplicationPlugins\El.Plugin.<версия>.bundle\` + `PackageContents.xml`; старые файлы предыдущей установки удаляются |
| Пишет запись об удалении | «Установка и удаление программ» → *Electrical Tools для AutoCAD*, версия 1.13.0 |
| Удаляет | та же запись одной кнопкой (`--uninstall`), либо кнопка «Удалить» в установщике |

Тихая установка для скриптов и развёртывания:

```
El.Tools.Setup.exe --silent                 установить (по умолчанию — в профиль пользователя)
El.Tools.Setup.exe --silent --uninstall     удалить
El.Tools.Setup.exe --silent --target D:\... установить в указанную папку плагинов (для тестов)
```

## Альтернативы (в релизе тоже лежат)

| Файл | Способ |
|---|---|
| `El.Plugin.2024.bundle.zip`, `El.Plugin.2027.bundle.zip` | распаковать папку `*.bundle` в `%APPDATA%\Autodesk\ApplicationPlugins\` — тоже без NETLOAD |
| `El.Plugin.2024.installer.zip`, `El.Plugin.2027.installer.zip` | старый путь: `NETLOAD` → `El.Plugin.dll` |

## Проверено

- установка в этой системе с реальным AutoCAD 2024 (R24.3): bundle встал чисто
  (`Contents\El.Plugin.dll` + `PackageContents.xml`, без мусора от прошлых версий);
- установка/удаление в отдельную папку: 4 файла → 0 файлов, повторная установка не ломается;
- CI-прогон `43864540406` (коммит `e80699c`): сборка установщика, **тихая установка на чистом
  раннере, разбор `PackageContents.xml`, удаление и проверка, что файлов не осталось** — всё зелёное;
- 79 тестов ядра, 0 падений; сборки 2024 (net48) и 2027 (net10) собираются в CI.

Проверка целостности скачанного:

```
sha256sum -c SHA256SUMS.txt
Get-FileHash -Algorithm SHA256 El.Tools.Setup.exe     # Windows
```

## Что внутри плагина (не менялось в этом релизе)

- **История ревизий:** `OMNI-SNAP`, `OMNI-AUTOSNAP` (авто-слепки при сохранении), `OMNI-HISTORY`,
  `OMNI-ARCHIVE` (сжатие в ZIP), `OMNI-RESTORE` (откат со страховочным слепком), `OMNI-DIFF`.
- **Инженерия схем:** топология (`EL-TRACE`, `EL-PATH`, `EL-WHATIF`), аудит (`EL-CHECK`, `EL-LOOPS`,
  `EL-CROSSING`, `EL-BOTTLENECK`, `EL-STATS`), спецификации (`AW33`, `AW33-CSV`, `AW33-HTML`),
  провода (`DrawWire`, `WireTable`), тепловая карта (`EL-HOTSPOTS`), ссылки на листы (`EL-CROSSREF`),
  отчёты HTML/md, BOM, штамп, реестр листов.
- **Границы вместо зависаний:** 4 млн ячеек в роутере, 4096 проб на препятствие, 2 млн проверок при
  сглаживании, 200 файлов за проход архивации — закреплено тестами.
